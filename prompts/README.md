## Try a recipe

1. Open a [recipe](recipes.md), copy its text, and use its suggested aspect ratio as a starting point.
2. Paste it into the [Vistella Playground](https://www.vistella.xyz/en/playground?utm_source=github&utm_medium=prompt_gallery&utm_campaign=visual_recipes).
3. Change one detail at a time: light, camera distance, material, or palette. Save the version that works for your project.

The [negative prompt guide](negative_prompts.md) has optional exclusions. [Asset notes](assets/README.md) record the prompts used to create the reference images; the [distribution kit](distribution-kit.md) contains ready-to-adapt social copy and channel links.
