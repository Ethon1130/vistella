## Other acquisition routes

1. **GitHub discovery:** Give the repository a concise description and relevant topics such as `ai-image-generation`, `prompt-engineering`, `image-prompts`, `design-inspiration`, and `visual-art`. Upload [`assets/repository-social-preview.jpg`](assets/repository-social-preview.jpg) in GitHub's repository **Settings → Social preview**. The supplied file is 1280 × 640 and under 1 MB, matching [GitHub's format guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview). Committing the file alone does not change the repository's social preview setting.
2. **Search landing pages:** Publish one useful page per image category on `vistella.xyz` with the matching prompt, steps, a relevant example image, a descriptive filename and alt text, and a direct Playground link. Keep the example provenance clear. Link these pages from this repository and vice versa. [Google's image guidance](https://developers.google.com/search/docs/appearance/google-images) recommends contextual text, descriptive filenames and alt text.
3. **Visual discovery:** Publish the 2:3 Amalfi poster or skincare image as a Pinterest Pin linked to the Playground, with the full recipe referenced in its description. Make future 2:3 variants for portrait and architecture only if this format brings qualified visits. [Pinterest recommends a vertical 2:3 image](https://business.pinterest.com/en-gb/creative-best-practices/) for mobile viewing.
4. **Community tutorials:** Share the full recipe, one useful lighting or composition lesson, and the reference image in communities that allow this kind of post. Link to the repository only when it helps readers reproduce the technique; follow each community's posting rules.
